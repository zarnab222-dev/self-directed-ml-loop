# Self-directed ML learning loop

A small set of [Claude Code](https://claude.com/claude-code) skills for running
a self-directed, AI-assisted applied-ML/robotics curriculum: one skill picks the
next atomic step, one verifies whether it actually counts, one finds resources
for a specific confusion, one runs a periodic alignment audit, and one runs a
research pass to (re)write the pedagogy contract the others follow.

This is a personal tool, shared as-is with a friend (and maybe a few others) —
not a product, not maintained on a schedule, no support promised.

## What's in here

```
skills/
  next-brick/            what to do right now
  check/                 did that last step actually count
  study-scout/           find resources for a specific pain point
  learning-stack-audit/  lightweight weekly alignment check
  learning-loop-storm/   full research refresh -> pedagogy contract
  storm/                 general-purpose grounded-research skill (dependency)
START-HERE.md            setup + the one-time diagnostic prompt
```

None of these contain anyone's personal curriculum, diagnostic answers, or
progress — that content lives in your own notes vault, which you create during
setup. The skills are just the mechanism.
